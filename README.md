# Площадка СПб

Android-приложение для поиска уличных спортивных площадок в Санкт-Петербурге и пригородах.

## Основные функции

| Функция | Что можно сделать |
| --- | --- |
| **Рядом со мной** | Найти до 20 площадок в радиусе 5 км. Список отсортирован по расстоянию по прямой, а на карте показаны те же площадки. |
| **Офлайн-каталог** | Открыть список из 130 площадок и карточки с адресами без сети. |
| **Карточка площадки** | Посмотреть фото при наличии, адресный ориентир, тип метки и примерный радиус поиска. |
| **Маршрут** | Открыть доступный сервис навигации из карточки площадки. |
| **Избранное** | Сохранить площадки на устройстве. |

Фото доступны у 115 площадок. Для фото и карты нужен интернет. Показатель уверенности в метке основан на типе источника, фактическая погрешность не измерена.

## Установка

1. Откройте [Releases](https://github.com/alenindevs13/ploshadka/releases) и скачайте APK.
2. Откройте APK на устройстве с Android 8.0 или новее.
3. Нажмите **Рядом со мной** и разрешите доступ к геолокации для поиска ближайших площадок.

## Исходники

- `android/` — манифест, Android WebView, геолокация, маршруты и чтение SQLite.
- `web/` — интерфейс, стили и метаданные площадок.
- `catalog/` — SQLite и CSV. В CSV указаны источники записей и ссылок на фото.
- `build.ps1` — локальная сборка для Windows.

## Сборка на Windows

Нужны JDK 17, Python 3, Android SDK Platform 35 и Android Build Tools 36.0.0. Команды `javac`, `keytool` и `python` должны быть доступны в PATH.

```powershell
pwsh -File .\build.ps1
```

Если SDK установлен в другом каталоге, передайте `-SdkPath`. APK появится в `build/`. Скрипт создаёт локальный ключ для тестовой сборки. Для обновления уже установленной версии нужен APK с прежней подписью.
